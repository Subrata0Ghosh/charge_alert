- **[videos/](file:///c:/Users/sulat/Desktop/projects/flutter_workspace/charge_alert/promo_assets/videos)**: Rendered MP4 videos, promotional reels, UGC cuts, YouTube shorts, and raw screen captures.
- **[scripts/](file:///c:/Users/sulat/Desktop/projects/flutter_workspace/charge_alert/promo_assets/scripts)**: Generation scripts (`.py`, `.js`, `.ps1`), concat lists (`concat_*.txt`), and HTML render templates.
